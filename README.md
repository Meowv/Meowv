## 👨‍💻 关于我 · About Me

- **后端是主场**：专注 .NET / C#，关注 ASP.NET Core、EF Core、系统设计与工程实践。
- **也喜欢跨端折腾**：用 Vue / TypeScript 构建 Web 应用，用 Kotlin / Jetpack Compose 开发 Android 应用，也尝试 Swift 原生 macOS 开发。
- **偏爱简单、好用的产品**：尤其关注本地优先、低使用门槛，以及真正影响体验的小细节。
- **持续写作与开源**：在 [meowv.com](https://meowv.com) 分享技术，也把个人想法放到 GitHub 上慢慢打磨。
